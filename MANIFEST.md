# Documentation package manifest

This package is intended to become the initial documentation skeleton of the GitHub repo `rtx3070-trtllm-latency-lab`.

## Root files

| File | Use |
|---|---|
| `README.md` | Public-facing project overview. |
| `STAGE1_LOCAL_AI_PROMPT.md` | First file to give to a local AI coding/execution agent. |
| `.gitignore` | Prevents committing models, engines, and large profiler binaries. |
